# دليل تصحيح الأخطاء

## أوامر التصحيح

```bash
npm run debug
npm run logs
expo start --clear
```

## نقاط التحقق الأساسية

1. **Firebase**: تأكد من صحة مفاتيح `.env.local` وتهيئة Authentication/Database/Storage.
2. **المفاتيح الحساسة**: لا تستخدم مفاتيح حقيقية داخل المستودع.
3. **الصلاحيات**: تحقق من أذونات الموقع والإشعارات داخل Expo.
4. **الأداء**: راقب وقت التحميل واستهلاك الذاكرة أثناء التشغيل.

## مشاكل شائعة سريعة

- خطأ اتصال Firebase: راجع `FIREBASE_DB_URL` وباقي القيم.
- فشل إشعارات: تأكد من سماح الجهاز بإشعارات Expo.
- بطء في الواجهة: امسح الكاش عبر `expo start --clear`.
