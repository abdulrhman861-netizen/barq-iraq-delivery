# 🧪 دليل التجربة العملي الشامل للتطبيق

## المرحلة 1: تحضيرات محلية سريعة

### الخطوة 1: إعداد ملف البيئة
```bash
cp .env.example .env.local
```

### الخطوة 2: تثبيت المتطلبات
```bash
npm install
npm install -g expo-cli
npm install -g eas-cli
expo --version
eas --version
```

### الخطوة 3: إعداد Firebase للاختبار
1. اذهب إلى Firebase Console
2. اختر مشروعك
3. فعّل:
   - Authentication (Phone + Email)
   - Realtime Database
   - Cloud Storage
   - Firestore (اختياري)
4. أدخل مفاتيح المشروع داخل `.env.local`

### الخطوة 4: إعداد Google Maps (اختياري)
1. اذهب إلى Google Cloud Console
2. أنشئ API Key للخرائط
3. أضفه إلى `.env.local`

## المرحلة 3: السيناريو الأول - تسجيل دخول عميل

1. فتح التطبيق (شاشة الترحيب)
2. اختيار الدور "عميل"
3. إدخال رقم الهاتف: `07700000001` (أو رقم عراقي صحيح)
4. استقبال OTP (يمكن استخدام OTP تجريبي في Firebase)
5. إدخال OTP
6. ملء البيانات:
   - الاسم: عميل تجريبي
   - البريد: customer@test.barq
   - العنوان: بغداد - الكرادة
7. التأكد من الوصول للصفحة الرئيسية وظهور الرصيد

---

## المرحلة 4: السيناريو الثاني - تسجيل طلبية جديدة

1. اختيار تاجر من الصفحة الرئيسية
2. إضافة منتجات (مثال: برجر + بيتزا)
3. مراجعة السلة والإجمالي
4. إدخال عنوان التوصيل
5. اختيار طريقة الدفع (COD أو المحفظة)
6. مراجعة الملخص
7. تأكيد الطلب
8. التحقق من إنشاء الطلب وظهوره في "طلباتي"

## المرحلة 5: السيناريو الثالث - تتبع الطلب الحي

3. مراجعة التفاصيل والحالة
4. عرض الخريطة
5. اختبار الدردشة مع الكابتن
6. مراقبة تحديث الحالة والإشعارات

## المرحلة 13: استكشاف المشاكل الشائعة

### "خطأ اتصال Firebase"
1. تحقق من `.env.local`
2. تأكد من المفاتيح
3. تحقق من تفعيل Realtime Database
4. نفّذ: `npm run debug`

### "OTP لا يصل"
1. تحقق من إعدادات Phone Auth
2. استخدم رقم اختبار Firebase
3. تأكد من إعدادات SMS

### "الخريطة لا تظهر"
1. تحقق من `GOOGLE_MAPS_API_KEY`
2. فعّل Maps API
3. اختبر المفتاح

### "بطء في الأداء"
1. نفّذ: `expo start --clear`
2. أغلق التطبيقات الخلفية
3. اختبر على جهاز أقوى
4. راجع السجلات: `npm run logs`
